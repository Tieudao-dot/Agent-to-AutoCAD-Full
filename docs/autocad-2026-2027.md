# Hỗ trợ AutoCAD 2026 và 2027 (nhánh `claude/acad-2026-2027`, chưa phát hành)

*Kiểm 11/11/2026. Một bộ cài chung cho AutoCAD 2022–2027.*

## Kết luận

| AutoCAD | Mã nội bộ | .NET lúc phát hành | Sau bản cập nhật | Bản plugin dùng |
| --- | --- | --- | --- | --- |
| 2022 / 2023 / 2024 | R24.1 / R24.2 / R24.3 | .NET Framework 4.8 | — | `Contents\ClaudeCAD.Plugin.dll` (net48) |
| 2025 | R25.0 | .NET 8 | .NET 10 (bản cập nhật 2025, AutoCAD.NET 25.0.2, 09/2026) | `Contents\2025\ClaudeCAD.Plugin.dll` (net8.0-windows) |
| 2026 | **R25.1** | .NET 8 | .NET 10 từ **2026.1.2** (AutoCAD.NET 25.1.1, 08/2026) | `Contents\2025\ClaudeCAD.Plugin.dll` (net8.0-windows, dùng chung với 2025) |
| 2027 | **R26.0** | **.NET 10** | — | `Contents\2027\ClaudeCAD.Plugin.dll` (net10.0-windows, bản mới) |

- **2026 dùng chung DLL với 2025:** cùng dòng R25 (tương thích nhị phân, ObjectARX SDK 25.1 dùng cho cả 2025 và 2026).
  Bản .NET 8 vẫn nạp được sau khi AutoCAD 2025/2026 cập nhật lên .NET 10: Autodesk ghi bản cập nhật chỉ đổi runtime,
  không đổi API, plugin cũ vẫn chạy nếu không dính thay đổi phá vỡ của .NET 10. Plugin không kèm
  `runtimeconfig.json` (thứ duy nhất Autodesk cảnh báo làm hỏng việc nạp). Không đưa bản net10 vào R25 vì AutoCAD
  2025/2026 chưa cập nhật vẫn chạy .NET 8 và sẽ không nạp được DLL .NET 10.
- **2027 cần bản riêng:** Autodesk ghi 2027 *không* tương thích nhị phân với 2025/2026, phải build lại với thư viện
  26.0 và .NET 10, và phải sửa SeriesMin/SeriesMax trong PackageContents.xml.
- **SeriesMax luôn ghi rõ** (R24.3, R25.1, R26.0): bản AutoCAD sau (R26.1+) chưa kiểm thì không tự nạp.

## API plugin dùng: so 2025 (25.0.1) với 2027 (26.0.0)

So danh sách kiểu / phương thức / trường trong chính các DLL của gói NuGet (AcMgd, AcCoreMgd, AcDbMgd, AdWindows,
AdUiPalettes, AcWindows…): 569 mục bị bỏ ở 26.0, gần hết là lớp nội bộ (launcher, ribbon, UAServerCaller,
`ShareViewTrayItem`). **Không mục nào plugin dùng bị bỏ.** Đã kiểm riêng:

- `KernelDescriptor`, `Manager.AcquireGraphicsKernel`, `GsView`, off-screen device (chụp ảnh bản vẽ) — còn.
  Trong XML doc 26.0 mất các hằng `KernelDescriptor.Drawing3D…` và `addRequirement(ulong)`; plugin dùng
  `addRequirement(UniqueString.Intern("3D Drawing"))` nên không ảnh hưởng.
- `Autodesk.Windows.Themes.ThemeManager` (`Instance`, `CurrentPaletteTheme`, `PropertyChanged`) và
  `Autodesk.Windows.Palettes.PaletteTheme` trong `AdUiPalettes.dll` — còn nguyên tên và assembly (theme đọc bằng
  reflection không đổi).
- `PaletteSet`, `TrayItem` / `StatusBar`, `Editor`, `Database`, `Transaction`, `SystemVariableChanged`,
  `PreTranslateMessage` — còn.
- `Color.FromColor(System.Drawing.Color)` bị bỏ khỏi XML doc 26.0; plugin chỉ dùng `Color.FromColorIndex` và hàm
  `Acad.FromColor` của chính mình.

Các `#if ACAD_R24 … #endif` trong code đều là nhánh .NET Framework; bản 2027 tự đi nhánh .NET (Core) như 2025.
Define `ACAD_R26` có sẵn cho chỗ nào sau này khác R25. Việc kiểm cuối cùng là CI build sạch bản net10 với
AutoCAD.NET 26.0.0.

Lưu ý Autodesk nêu cho 2027 + .NET 10 bản đầu: kéo-thả từ palette tự viết vào vùng vẽ có thể lỗi
`InvalidCastException`. ClaudeCAD không kéo-thả từ palette vào bản vẽ (chỉ kéo ảnh *vào* ô chat), nhưng vẫn thử
mục này trên 2027.

## Thay đổi

- `plugin/ClaudeCAD.Plugin/ClaudeCAD.Plugin.csproj`: TFM thứ 3 `net10.0-windows` → `bin\<Config>\acad2027\`,
  define `ACAD_R26`, NuGet `AutoCAD.NET 26.0.0`, chế độ Install đọc `$(AcadDir2027)`.
- `bundle/PackageContents.xml`: component .NET 8 nới lên R25.0–R25.1; thêm component `ClaudeCAD2027` R26.0–R26.0
  (`./Contents/2027/`); gói tổng R24.1–R26.0.
- `bundle/make-bundle.mjs`: chép DLL thứ 3 vào `Contents\2027` (`--dll2027`).
- `installer/ClaudeCAD.iss`: TRUSTEDPATHS thêm R26; không build được bộ cài nếu thiếu một trong 3 DLL; chữ 2022–2027.
  Không đụng phần key / kích hoạt.
- `installer/install.ps1`: TRUSTEDPATHS thêm R26; chữ 2022–2027.
- CI: cài .NET 8 + 10, build cả 3 bản, kiểm đủ 3 DLL. UI test vẫn chạy trên net8.
- Sidecar: system prompt ghi AutoCAD 2022–2027; test manifest kiểm đúng DLL theo series và SeriesMax luôn ghi rõ.
- Log khi nạp, `CLAUDECHATSELFTEST` và *Gửi báo cáo lỗi* ghi bản build (2022–2024 net48 / 2025–2026 net8.0 / 2027
  net10.0), runtime .NET thật AutoCAD đang chạy (2025/2026 sau cập nhật là .NET 10) và ACADVER.
- Setup.exe và install.ps1 cảnh báo (vẫn cho cài tiếp) khi máy không có AutoCAD 2022–2027 bản đầy đủ, hoặc chỉ có bản
  mới hơn 2027. Cài ngầm thì không hỏi.
- CI kiểm từng DLL trong bundle đúng .NET và đúng thư viện AutoCAD (24.x / 25.x / 26.x), kiểm cú pháp install.ps1,
  build từng bản tuần tự; mỗi bản có thư mục `obj` riêng (trước đây 3 bản build song song đụng file của nhau).
- Sửa lỗi cũ (có cả trên `main` v0.9.3): `install.ps1` không chạy được vì lỗi cú pháp `"Node.js v$major: OK"`.
