# Bộ cài ClaudeCAD

> **Bản Agent to AutoCAD Full chưa có bộ cài riêng.** Các link tải bên dưới vẫn là bộ cài ClaudeCAD của dự án gốc
> (bản 2D). Sẽ đổi khi chủ dự án chốt nơi phát hành của bản Full: xem
> [`../docs/cho-tro-ve-repo-goc.md`](../docs/cho-tro-ve-repo-goc.md).

## Tải bộ cài (luôn là bản mới nhất)

**[⬇ ClaudeCAD-Setup.exe](https://github.com/Tieudao-dot/Agent-to-Autocad/releases/latest/download/ClaudeCAD-Setup.exe)**

- Link này không đổi: mỗi khi plugin có bản mới, link tự trỏ sang bộ cài mới. Không cần đăng nhập GitHub.
- Các bản trước và file khác (`ClaudeCAD-<version>.zip`, `install.ps1`, `latest.json`): [trang phát hành](https://github.com/Tieudao-dot/Agent-to-Autocad/releases).
- File bộ cài không nằm trực tiếp trong thư mục này vì GitHub không nhận file lớn hơn 100 MB trong repo (bộ cài khoảng 140 MB vì kèm sẵn Node.js và Claude Code). CI tự build và đăng bộ cài mỗi khi có phiên bản mới trên `main`.

## Kiểm tra file tải về

Trang [phát hành](https://github.com/Tieudao-dot/Agent-to-Autocad/releases/latest) ghi kích thước và mã SHA-256 của `ClaudeCAD-Setup.exe`. Nếu bộ cài báo "The source file is corrupted", mở PowerShell trong thư mục chứa file và chạy `Get-FileHash .\ClaudeCAD-Setup.exe` — mã khác với trang phát hành nghĩa là file tải về bị hỏng: tải lại vào ổ máy (không chạy từ ổ mạng / USB), hoặc tạm tắt phần mềm diệt virus khi cài.

## Cài đặt (4 bước)

1. Tải `ClaudeCAD-Setup.exe` ở link trên.
2. Chạy file. Hộp đầu tiên hỏi ngôn ngữ (**Tiếng Việt** / **English**, mặc định Tiếng Việt): bộ cài nói theo ngôn ngữ này và plugin cũng mở bằng ngôn ngữ đó ở lần đầu (đổi lại trong ⚙ bất cứ lúc nào; xem mục *Ngôn ngữ / Language*). Nếu Windows hiện "Windows protected your PC" → **More info → Run anyway** (bộ cài chưa ký số). Không cần quyền admin, không cần cài Node.js hay Claude Code. Nên đóng AutoCAD trước khi cài.
3. **Kích hoạt:** bộ cài hiện **mã máy** và dòng *"Liên hệ Zalo owner: 0344644415"*; yêu cầu được gửi tự động cho chủ plugin (email + một dòng **Chờ duyệt** trong bảng thiết bị của chủ plugin). Hai cách: **(a)** chờ chủ plugin duyệt — bấm **Next** cài tiếp không cần key, sau khi được duyệt mở AutoCAD là tự dùng được (hoặc bấm **Kiểm tra lại** trong khung chat để dùng ngay); **(b)** nhận **key** qua Zalo, dán vào ô **Key kích hoạt** rồi bấm **Next**. Máy không có mạng: chủ plugin gửi mã 2–3 dòng (`CCL1…`, `CCS1…`, `CCF1…`); dán **đủ các dòng** vào cùng ô (ô nhận nhiều dòng). Dán sau khi cài cũng được: ô key trên thẻ **Kích hoạt** của khung
chat, ô **Dùng mã** trên thẻ 🔒 (máy đã kích hoạt nhưng đang khóa), hoặc ⚙ ▸ Tài khoản AI ▸ **Dán mã của chủ plugin** (máy
đang dùng; ví dụ dòng gói mới). Máy đã kích hoạt rồi (cài đè, cập nhật) thì không hỏi lại, trừ máy đang có **ClaudeCAD bản gốc** (xem mục *Nâng cấp từ ClaudeCAD bản gốc*).
4. Trang cuối bộ cài: giữ ô **Đăng nhập Claude ngay** rồi bấm **Finish** → trình duyệt mở trang cấp quyền, bấm **đồng ý** bằng tài khoản Claude Pro/Max (một cửa sổ đen hiện lên và tự đóng khi xong). Không cần mở AutoCAD. Máy đã đăng nhập sẵn thì ô này không hiện. Sau đó mở AutoCAD 2022–2025 là dùng được (2026 và 2027: đang làm, chưa phát hành) (nếu bỏ qua bước này, lần đầu mở AutoCAD plugin tự mở trang đăng nhập).

Sau khi cài: gõ `CLAUDECHATSELFTEST` để tự kiểm tra (báo cáo ✓/✗ mở trong Notepad). Mở khung chat: `CLAUDECHAT`, `CC` hoặc **Ctrl+Shift+Space**.

### Khi bộ cài báo file đang được dùng

*(Sửa 14/11/2026, TT-01.)* AutoCAD đang mở thì các file của plugin đang được dùng, bộ cài không thay được:

- Bộ cài hiện hộp **"AutoCAD đang mở."**: lưu bản vẽ, đóng hết AutoCAD rồi bấm **Thử lại**. Bấm **Hủy** thì thoát, máy
  giữ nguyên bản đang có. Bộ cài **không tự tắt AutoCAD** (tránh mất bản vẽ chưa lưu).
- Tiến trình phụ của plugin còn chạy sau khi đóng AutoCAD (`node.exe`, `claude.exe` trong thư mục plugin) thì bộ cài tự
  tắt, không đụng `node.exe` khác của máy.
- Vẫn còn file bị giữ: bộ cài dừng trước khi thay gì và báo **"Hãy khởi động lại máy rồi chạy lại bộ cài, trước khi mở
  AutoCAD."** Làm đúng như vậy là cài được.
- Cài ngầm (`/VERYSILENT`) khi AutoCAD đang mở: bộ cài dừng (không hỏi), log ghi lý do; đóng AutoCAD rồi chạy lại.
- Hộp tiếng Anh *"Setup was unable to automatically close all applications…"* (Try again / Ignore / Cancel) của bản cũ
  không còn xuất hiện. Gặp ở bộ cài cũ: bấm **Cancel installation**, đóng AutoCAD (hoặc khởi động lại máy) rồi chạy lại.

## Cập nhật

- Khung chat tự kiểm tra bản mới mỗi ngày và báo trong chat. Gõ `CLAUDECHATUPDATE` để tải; bản mới được cài khi đóng AutoCAD.
- Hoặc tải lại `ClaudeCAD-Setup.exe` ở link trên và chạy đè. Skill cậu đã thêm/sửa, macro, mẫu lệnh, lịch sử chat đều được giữ nguyên.

## Nâng cấp từ ClaudeCAD bản gốc

*Chốt 12/11/2026.* Bản **Agent to AutoCAD Full** thay ClaudeCAD bản gốc (chỉ 2D) như một bản nâng cấp. Hai bản dùng chung
danh tính kỹ thuật (mã cài đặt, thư mục `ClaudeCAD.bundle`, lệnh `CLAUDECHAT` / `CC`, thư mục dữ liệu `ClaudeCAD`), nên
cài đè là xong, không gỡ bản cũ trước.

1. Đóng AutoCAD, chạy `ClaudeCAD-Setup.exe` của bản Full (tên file giữ nguyên).
2. Bộ cài tự nhận ra bản đang có. Máy đang có bản gốc thì hiện hộp thoại: *"Máy này đang có ClaudeCAD (bản gốc, chỉ 2D),
   phiên bản …. Cài Agent to AutoCAD Full sẽ thay bản này. Lịch sử chat, cài đặt và đăng nhập Claude được giữ. Key cũ
   không dùng được: máy sẽ xin kích hoạt lại…"*. Bấm **Tiếp tục** để cài, **Hủy** để thoát bộ cài (máy giữ nguyên bản
   gốc, không có gì thay đổi).
3. Trang **Kích hoạt** hiện lại (dù máy đã có key của bản gốc), mã máy giữ như cũ. Yêu cầu tự gửi tới máy chủ của bản
   Full; chủ plugin duyệt máy ở bảng thiết bị mới, hoặc gửi key mới.
4. Chủ plugin chọn gói cho máy ở ô **Gói** (2D / 3D / Full; mặc định 2D). Sau đó đổi gói chỉ cần sửa ô Gói: máy nhận ở lần
   kiểm tra kế tiếp (mở AutoCAD, ~6 giờ/lần, hoặc bấm **Kiểm tra lại**), không cài lại.

| Giữ nguyên | Mất / đổi |
| --- | --- |
| Lịch sử chat, cài đặt ⚙, đăng nhập Claude (hoặc API key), skill đã thêm / sửa, macro, mẫu lệnh `/`, phiên bản DWG, ghi chú dự án | Key và trạng thái kích hoạt của bản gốc: không dùng được với máy chủ bản Full, máy xin kích hoạt lại |
| Lệnh `CLAUDECHAT`, `CC`, `CLAUDECHATSELFTEST`… | Tên hiển thị thành **Agent to AutoCAD Full** (danh sách ứng dụng của Windows chỉ còn một mục này, khung chat, ⚙) |
| | Bản cập nhật của bản gốc đã tải sẵn chờ cài (nếu có) bị bỏ, để nó không cài ngược lại lúc đóng AutoCAD |

- **Skill mẫu 2D cũ** (`ve-kien-truc`, `ve-mep`, `ve-ha-tang`): bộ cài không ghi đè skill đã có trên máy, nên máy nâng
  cấp giữ bản cũ của 3 skill này (không có dòng `plan: 2d`). Không cần sửa tay: trợ lý vẫn coi chúng là skill 2D, máy gói
  3D không nạp. Muốn một skill mẫu nạp ở mọi gói thì thêm dòng `plan: all` vào phần đầu của nó.
- **Cài ngầm** (`/VERYSILENT`, `/SILENT`): không hỏi, cài đè luôn và ghi vào log cài đặt (`%TEMP%\Setup Log …txt`) hai
  dòng *"existing install: original 0.9.3 …"* và *"silent install: replacing …"*. Thêm `/KEY=` (key của máy chủ bản Full)
  để kích hoạt ngay.
- Bộ cài nhận ra bản đang có từ file trong thư mục `ClaudeCAD.bundle`: `Contents\edition.json` (`"edition": "full"`: bản Full,
  cài đè bình thường không hỏi); không có file đó mà `Contents\update-config.json` trỏ repo gốc `Agent-to-Autocad/`: bản
  gốc; không đọc được cả hai: coi như bản gốc (vẫn hỏi).
- **Lưu ý trước khi có máy chủ kích hoạt riêng:** bộ cài build từ nhánh hiện còn trỏ máy chủ kích hoạt của bản gốc. Đừng
  cài thử lên máy khách cho tới khi luồng chính gắn URL + khóa công khai của bản Full.

## Ngôn ngữ / Language

- ⚙ ▸ **Chung — Giao diện ▸ Ngôn ngữ / Language**: **Tiếng Việt** (mặc định) hoặc **English**. Chữ trên khung chat (nút, thẻ, thông báo, nhãn lệnh, lời báo lỗi, báo cáo tự kiểm tra) đổi ngay; Claude trả lời bằng ngôn ngữ mới từ tin nhắn tiếp theo.
- **English chỉ đổi giao diện và câu trả lời, chữ trên bản vẽ giữ tiếng Việt** (tên phòng, tiêu đề bảng, khung tên, tên tờ, tên cọc, mô tả layer, tiêu đề cột Excel…), theo chuẩn bản vẽ Việt Nam. Muốn chữ nào trên bản vẽ bằng tiếng Anh thì nhờ Claude đổi.
- Cài ngầm: thêm `/LANG=english` (hoặc `/LANG=vietnamese`) để chọn ngôn ngữ đầu tiên mà không hiện hộp hỏi.
- *English:* ⚙ ▸ **Language** switches the palette to English at once; Claude answers in English from the next message. Texts drawn into the drawing stay Vietnamese.

## Cài cho nhiều máy

- Cài ngầm, không hỏi gì: `ClaudeCAD-Setup.exe /VERYSILENT /KEY=XXXX-XXXX-XXXX-XXXX` (key của đúng máy đó; mỗi máy vẫn cần bấm **Đăng nhập Claude** một lần). Máy đang có bản gốc cũng không bị hỏi: bộ cài cài đè và ghi log (mục *Nâng cấp từ ClaudeCAD bản gốc*).
- Hoặc bằng PowerShell: giải nén `ClaudeCAD-<version>.zip`, đặt `install.ps1` cạnh thư mục `ClaudeCAD.bundle`, chạy `powershell -ExecutionPolicy Bypass -File install.ps1`.

## Duyệt và quản lý thiết bị (chủ plugin)

- Mỗi máy chạy bộ cài (hoặc mở khung chat khi chưa kích hoạt) tự hiện thành một dòng **Chờ duyệt** trong Google Sheet **"ClaudeCAD – Thiết bị"** của chủ plugin, kèm email **"[ClaudeCAD] Yêu cầu kích hoạt: <tên máy> (<user>)"** có mã máy và **KEY** dự phòng.
- **Cho dùng:** đổi ô **Trạng thái** của dòng đó thành `Active` → lần mở AutoCAD kế tiếp máy đó tự dùng được (hoặc bấm **Kiểm tra lại** để dùng ngay), **không cần key**. Hoặc gửi KEY trong email qua Zalo.
- **Chống spam:** tối đa 30 máy mới mỗi giờ được thêm vào bảng, 10 email mỗi giờ và 40 email mỗi ngày; máy đã `Active` xin lại không gửi email thừa; tên máy gửi lên không chạy được như công thức trong bảng.
- **Không né được lệnh khóa:** link máy chủ nằm sẵn trong plugin (xóa file cấu hình không tắt được kiểm tra); chỉnh lùi đồng hồ máy để kéo dài 7 ngày cũng bị phát hiện.
- ⚠️ **Đừng đổi tên trang "Thiết bị", đừng chèn / đổi thứ tự cột** trước cột "Ghi chú" (máy chủ đọc cột theo vị trí). Chia sẻ bảng tính thì chỉ cho quyền **Người xem**: người có quyền sửa xem được khóa bí mật trong Apps Script.
- **Ngưng cho dùng:** đổi thành `Disabled` → máy bị khóa ở lần kiểm tra kế tiếp (plugin kiểm tra mỗi lần mở AutoCAD và ~6 giờ/lần; máy cố tình ngắt mạng cũng chỉ dùng thêm tối đa 7 ngày). Đổi lại `Active` là máy dùng tiếp ngay, không cần key mới.
- **Gói của máy** (bản Full, chưa phát hành): đổi ô **Gói** thành `2D`, `3D` hoặc `Full`. Máy nhận gói mới ở lần
  kiểm tra kế tiếp (mở AutoCAD, ~6 giờ/lần, hoặc **Kiểm tra lại**), khung chat báo "Gói đã đổi sang …" và hiện
  "Gói: …" trên thanh trên cùng và trong ⚙. Gói 3D có đường cơ bản và block không thuộc tính nhưng không có chữ (kể cả thuộc tính
  block), kích thước, hatch, layout, in PDF, sửa 2D; Claude không thấy và không chạy được lệnh ngoài gói. Máy mới, ô Gói trống hoặc gõ sai nhận `2D` (đã chốt 12/11/2026).
- Cột **Lần cuối dùng** và **Phiên bản** cho biết máy nào còn đang dùng plugin.
- Key chỉ dùng được trên đúng máy có mã đó. Cài lại Windows / thay mainboard thì mã máy đổi, máy xin duyệt lại như máy mới.
- Máy không có mạng, cài máy chủ kích hoạt + bảng thiết bị, tạo key bằng tay: [`activation/README.md`](../activation/README.md).

## Khi có lỗi trên máy khác

Người dùng máy đó bấm **⚙ ▸ Gửi báo cáo lỗi** (hoặc nút cùng tên trên thẻ lỗi) → file `ClaudeCAD-baocao-<tên máy>-<ngày giờ>.zip` hiện trên Desktop → gửi file đó cho người hỗ trợ. Nên gõ `CLAUDECHATSELFTEST` trước để báo cáo có kết quả tự kiểm tra mới nhất.

File gồm: thông tin máy / AutoCAD / plugin, trạng thái trợ lý và tài khoản, log 3 ngày gần đây, kết quả tự kiểm tra, log cài đặt. **Không** có lịch sử chat, bản vẽ, ghi chú dự án; API key và token trong log được che.

## Đổi tài khoản AI

**⚙ ▸ Tài khoản AI**: dòng "Đang dùng: …" cho biết tài khoản hiện tại.

- **Đổi tài khoản**: đăng xuất rồi đăng nhập tài khoản Claude khác trên trình duyệt.
- **Đăng xuất**: đăng xuất trên máy này (cả Claude Code nếu máy có dùng).
- **Dùng API key**: dán API key Anthropic (console.anthropic.com, trả theo lượng dùng). Key được lưu mã hóa cho riêng tài khoản Windows đó và được ưu tiên hơn tài khoản Claude; **Xóa key đã lưu** để quay lại tài khoản Claude.

Chỉ dùng được Claude (tài khoản Pro/Max/Team hoặc API key Anthropic); plugin không chạy với ChatGPT hay Gemini.

## Gỡ cài đặt

Windows **Settings → Apps → ClaudeCAD for AutoCAD → Uninstall** (hoặc `install.ps1 -Uninstall`). Dữ liệu của cậu (lịch sử chat, macro, mẫu lệnh) nằm trong `%LocalAppData%\ClaudeCAD` và `%AppData%\ClaudeCAD`, xóa tay nếu không cần nữa.

## Lịch sử phiên bản

| Phiên bản | Nội dung chính |
| --- | --- |
| Full · Nâng cấp đợt F4 *(nhánh `full/nang-cap-f4`, chưa phát hành; gồm F2 + F3)* | **Mở chat nhanh hơn:** trợ lý khởi động Claude sẵn khi mở AutoCAD (không tốn token trước tin đầu, tự dựng lại khi bị tắt), tin đầu không phải chờ khởi động; Claude chỉ nạp đủ mô tả 25 lệnh hay dùng, lệnh khác tự tìm khi cần — mở chat bớt khoảng 2/3 token (máy Full ~60k → ~20k, ước tính). **Xuất bảng ra Excel:** thống kê block, diện tích phòng / layer, khối lượng 3D theo layer, va chạm khối ("… xuất ra Excel") ra file .xlsx cạnh bản vẽ, tiếng Việt đúng dấu, số cộng được, không cần cài Excel; máy gói 3D cũng xuất được bảng 3D; file đã có thì Claude hỏi trước khi ghi đè. **Tắt nạp gọn (đường lui, không cần build lại):** thử thật thấy Claude tìm sót lệnh thì đặt biến môi trường `CLAUDECAD_DEFER_TOOLS=0` (hoặc tạo file trống `%LocalAppData%\ClaudeCAD\tool-search-off`) rồi mở lại AutoCAD: mọi lệnh nạp đủ mô tả như trước F4 (tốn token như cũ); xóa biến / file là bật lại. Sau khi bật / tắt công tắc, bấm **Chat mới** (cuộc chat dở có thể đã dùng cách tìm lệnh mà công tắc tắt).
